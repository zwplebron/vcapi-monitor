# Deepseek 用量监控

一款运行在 macOS 上的桌面悬浮窗应用，实时监控 Deepseek 开放平台的账号余额。

## 功能

- 实时显示账号余额（每 5 分钟自动刷新，支持手动刷新）
- 交通信号灯提示：绿色（余额充足）、黄色（余额偏低）、红色（余额告急）
- 今日消费、本周消费金额推算
- 悬浮窗置顶/隐藏控制
- 全局快捷键快速显示/隐藏

## 安装

1. 打开终端，运行打包脚本：
   ```bash
   /usr/bin/python3 ~/Desktop/Deepseek用量监控/build_app.py
   ```
2. 将生成的 `DeepseekMonitor.app` 拖到 `Applications` 文件夹
3. 双击运行

## 获取 API Key

1. 打开 https://platform.deepseek.com ，注册或登录
2. 左侧菜单点击「API Keys」
3. 点击「创建 API Key」，输入名称后确认
4. **立即复制保存**（格式为 `sk-xxxxxxxxxxxxxxxx`，平台不会再次显示）

## 使用

### 首次启动
1. 输入你的 API Key（`sk-` 开头）
2. 点击「绑定」

### 日常使用
- 悬浮窗会自动显示余额和信号灯状态
- 点击「刷新」立即更新数据
- 点击「📌」切换窗口置顶/取消置顶
- 点击「—」隐藏窗口（点击 Dock 图标恢复）
- 点击「✕」退出程序
- 快捷键 `Cmd + Shift + D` 快速显示/隐藏（需要先安装 pynput）

### 信号灯说明

| 灯色 | 余额范围 | 含义 |
|------|---------|------|
| 绿灯 | > 10 元 | 余额充足 |
| 黄灯 | 2 ~ 10 元 | 余额偏低，建议关注 |
| 红灯 | < 2 元 | 余额告急，请尽快充值 |

## 账号管理

点击悬浮窗「账号设置」可以：
- 查看当前绑定的 API Key
- 更换 API Key
- 解绑账号

## 常见问题

**Q: 提示"刷新失败，请检查网络"？**
A: 检查网络连接，确认能访问 https://api.deepseek.com

**Q: 消费数据显示为 ¥0.00？**
A: 首次启动时没有历史数据，刷新几次后会自动追踪计算

**Q: 快捷键不生效？**
A: 需要安装 pynput（`pip3 install pynput`）并在系统设置中授予终端或应用的「辅助功能」权限

## 数据存储

配置和余额历史存储在：
```
~/Library/Application Support/DeepseekMonitor/
```
