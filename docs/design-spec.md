# UI 设计规范

## 色彩系统

| 用途 | 颜色名称 | HEX | 说明 |
|------|---------|-----|------|
| 主背景 | 淡蓝 50 | `#E3F2FD` | 窗口整体背景 |
| 强调色 | 蓝色 500 | `#2196F3` | 按钮、标题、分隔线 |
| 深色强调 | 蓝色 700 | `#1976D2` | 按钮悬停、标题文字 |
| 标题栏背景 | 蓝色 100 | `#BBDEFB` | 自定义标题栏 |
| 文字主色 | 灰 900 | `#212121` | 金额、标签 |
| 文字次要 | 灰 600 | `#757575` | 辅助说明文字 |
| 信号灯绿 | 绿色 500 | `#4CAF50` | 余额充足指示灯 |
| 信号灯黄 | 琥珀 500 | `#FFC107` | 余额不足指示灯 |
| 信号灯红 | 红色 500 | `#F44336` | 余额告急指示灯 |
| 信号灯灭 | 灰 300 | `#E0E0E0` | 非当前档位的灯 |
| 卡片背景 | 白色 | `#FFFFFF` | 用量信息卡片 |
| 错误提示 | 红色 600 | `#E53935` | API 错误/失败提示 |

## 窗口尺寸

| 窗口 | 宽度 | 高度 | 说明 |
|------|------|------|------|
| 悬浮窗主窗口 | 280px | 340px | 默认大小，不可调整 |
| 绑定窗口 | 400px | 320px | 首次绑定 |
| 账号设置窗口 | 400px | 280px | 设置弹窗 |

## 字体系统

| 用途 | 字体 | 大小 | 粗细 |
|------|------|------|------|
| 标题栏 | SF Pro Display (系统默认) | 13px | 500 |
| 余额数字 | SF Pro Display | 28px | 700 |
| 消费标签 | SF Pro Display | 11px | 400 |
| 消费数值 | SF Pro Display | 13px | 500 |
| 更新时间 | SF Pro Display | 10px | 400 |
| 按钮文字 | SF Pro Display | 12px | 500 |

## 信号灯规格

- 每个灯：直径 18px 的圆形
- 三灯间距：12px（圆心到圆心）
- 灯框（外壳）：深灰色 `#424242`，外圈直径 22px，2px 边框
- 排列方式：水平居中，位于余额数字上方
- 当前档位灯：填充对应颜色，外发光效果（通过绘制更大半透明圆实现）

## 按钮样式

| 状态 | 背景色 | 文字色 | 边框 |
|------|--------|--------|------|
| 默认 | `#2196F3` | `#FFFFFF` | 无 |
| 悬停 | `#1E88E5` | `#FFFFFF` | 无 |
| 次要按钮 | 透明 | `#2196F3` | 1px `#2196F3` |
| 危险按钮（解绑） | 透明 | `#E53935` | 1px `#E53935` |

## 布局间距

- 窗口内边距：左右 16px，上下 12px
- 组件间距：12px
- 分隔线：1px 高，`#BBDEFB` 颜色，左右撑满（margin 8px）
- 按钮间距：8px

## 标题栏

- 高度：32px
- 背景色：`#BBDEFB`
- 左侧标题文字，左对齐，padding-left: 10px
- 右侧图标按钮组，右对齐，每个按钮 28x28px
- 标题栏同时作为窗口拖动区域

## 交互反馈

- 按钮点击：颜色加深 100ms 过渡
- 数据加载中：显示 "刷新中..." 文字，按钮禁用
- 网络错误：文字提示 "刷新失败，请检查网络"，保留上次数据
- 用户输入错误 API Key：弹窗提示 "API Key 无效，请检查后重试"
