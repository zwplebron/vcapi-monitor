# 需求规格说明书

## 项目概述

一款运行在 macOS 上的桌面悬浮窗软件，实时监控 Deepseek 开放平台的账号用量数据。

## 用户角色

- 普通用户：Deepseek 开放平台的使用者，需要实时了解账号余额和用量情况

## 功能需求

### F1: 账号绑定
- 首次启动时，显示绑定窗口，用户输入 Deepseek API Key
- 提供"如何获取 API Key"的帮助指引
- 绑定后 API Key 加密存储在本地
- 关闭软件重新打开时无需重新绑定

### F2: 实时用量监控
- 显示剩余金额（总余额，单位：元）
- 显示本日消费金额和 Tokens
- 显示本周消费金额和 Tokens
- 每 5 分钟自动刷新数据
- 支持手动刷新（手动刷新后 5 分钟计时器重置）

### F3: 余额指示灯
- 交通信号灯样式（红、黄、绿三灯并排）
- 绿灯：余额 > 10 元
- 黄灯：2 元 < 余额 ≤ 10 元
- 红灯：余额 ≤ 2 元
- 仅当前区间对应的灯亮起，其余为灰色

### F4: 悬浮窗控制
- 窗口始终置顶于桌面（可切换）
- Pin 按钮：一键切换置顶/取消置顶
- 隐藏按钮：隐藏窗口，程序后台运行
- 全局快捷键 `Cmd+Shift+D`：快速显示/隐藏窗口
- 关闭按钮：退出程序

### F5: 账号管理
- 查看当前绑定的 API Key（部分隐藏显示）
- 解绑账号（清除配置，回到绑定窗口）
- 更换绑定（更新 API Key）

### F6: 单账号模式
- 仅支持绑定一个账号
- 无需账号切换功能

## 非功能需求

### N1: 环境要求
- 操作系统：macOS
- 无需用户手动安装任何依赖
- 双击 .app 即可运行

### N2: 性能
- 启动时间 < 3 秒
- 数据刷新延迟 < 5 秒（API 响应时间除外）
- 内存占用 < 100MB

### N3: 安全性
- API Key 不在本地明文存储
- 所有 API 请求通过 HTTPS

### N4: 兼容性
- 支持 macOS 10.15 (Catalina) 及以上版本

## 界面风格

- 简洁直观，主色调淡蓝色
- 悬浮窗约 280x340 像素
- 可拖动到屏幕任意位置
