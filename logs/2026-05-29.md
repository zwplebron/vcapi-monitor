## 遇到的问题
- tkinter 对“窗口本身圆角裁剪”的跨平台支持有限
  - 解决方案：使用透明背景 + Canvas 圆角外壳实现视觉圆角，并在透明能力不可用时回退到普通背景
- 首版优先尝试颜色透明，在当前 macOS/Tk 环境中未产生圆角效果
  - 解决方案：改为 macOS 下优先启用 `systemTransparent`
- 内容层透明后会露出桌面背景
  - 解决方案：移除满宽内容层，让各组件直接放在圆角底板上
- Codex 暂未发现面向普通用户的公开余额查询 API
  - 解决方案：建议 V2.0.0 先读取本地 `rate_limits` 快照，显示剩余百分比
- V2.0.0 当前 Codex credits balance 可能为空
  - 解决方案：界面以剩余百分比为核心，credits 余额仅在快照存在时展示
- 根目录 `MenuBarHelper` 二进制可能落后于 Swift 源码
  - 解决方案：重新编译 Helper，并提醒测试前彻底重启应用
- 账号设置页的 Codex 复选框此前绑定了即时保存逻辑
  - 解决方案：改为仅在点击“保存”后统一持久化，并在必要时触发主窗口重建
- 状态栏 Helper 与 Python 启动逻辑都曾使用 `¥ --.--` 作为初始占位
  - 解决方案：统一改为图标模式 `▪`，避免启动时闪出误导性余额
